# 논산 대물낚시

논산시 최대 규모 낚시점 대물낚시의 공식 랜딩 페이지입니다.

- 전화: 041-736-4100

## 개발

Next.js 15, React 19, Tailwind CSS 4 기반의 정적 사이트입니다.

```bash
npm install
npm run dev
```

`main` 브랜치에 변경 사항을 푸시하면 GitHub Actions가 정적 빌드를 생성하고 GitHub Pages로 자동 배포합니다.
